# JCG_Q20-openwrt
JCG_Q20从原版系统刷入openwrt\老毛子固件教程

刷机顺序:
1.从官方固件模式，在系统升级界面上传刷入“**pb-boot.img**”
进入不死模式，可以进入192.168.1.1刷入其他包
后续刷机出现问题可以长按多次进入boot模式（PS:按照我刷死机的反应，机指示灯长闪加短闪，插网线也获取不了网络，路由器无限重启）
2.等待指示灯有规律的呼吸后，进入192.168.1.1上传刷入“**底包-factory.bin**”
3.等待重启过后，插网线，查看IP，根据网关IP，进入极简版openwrt，在升级固件那里上传刷入
“**openwrt-02.01.2024-ramips-mt7621-jcg_q20-squashfs-sysupgrade.bin**”
4.刷机完毕，自己折腾！

篇外：第二步，也可以直接输入“**原系统升级刷入老毛子.bin**”
再分享一个定制openwrt刷机包的网站“https://openwrt.ai/”
注册后有免费额度，详细信息自己到官网查阅
